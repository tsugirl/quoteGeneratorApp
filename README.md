# Quote Generator App

Учебный проект в рамках дисциплины "Разработка приложений на языке Котлин". Приложение для Android на языке Kotlin, позволяющее получать случайные цитаты, сохранять их в избранное и делиться ими с другими пользователями.

---

## Основное описание

Приложение представляет собой современный инструмент для работы с цитатами:

* Получение случайных цитат с внешнего API
* Отображение автора цитаты
* История последних 5 показанных цитат
* Возможность добавить цитату в избранное
* Просмотр, удаление и повторное использование избранных цитат
* Шейринг цитат 

---

## Функционал

### Main Screen

* Отображение цитаты и её автора
* Кнопки навигации: предыдущая / следующая цитата из истории
* Кнопка «Новая цитата» — загрузка новой цитаты с API
* Кнопка «Добавить в избранное»
* Кнопка «Поделиться цитатой»

### Favorites Screen

* Список добавленных в избранное цитат
* Кнопка «Поделиться» для каждой цитаты
* Кнопка «Удалить из избранного»
* Навигация обратно на главный экран

### История цитат

* Хранение последних 5 показанных цитат

---

## Используемые технологии

* **Язык:** Kotlin
* **Платформа:** Android (SDK 21+)
* **UI:** RecyclerView
* **Сетевые запросы:** OkHttp
* **Парсинг JSON:** Gson
* **Асинхронность:** Kotlin Coroutines
* **Хранение данных:** SharedPreferences

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/tsugirl/quoteGeneratorApp.git
```

2. Откройте проект в **Android Studio**
3. Синхронизируйте Gradle (compileSdk = 34, targetSdk = 34, minSdk = 26)
4. Запустите приложение на эмуляторе или реальном устройстве, собрав APK

---

## Используемый API

Цитаты загружаются с сервиса:

```
https://thequoteshub.com/api/random-quote
```

API возвращает JSON с текстом цитаты и автором.
